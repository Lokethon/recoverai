## og-image.png — worth adding

`index.html` references `og-image.png` for link previews. Until you add it, sharing the live URL on LinkedIn or WhatsApp shows a bare link instead of a preview card. Since your PromptWars submission includes a LinkedIn post, this is a cheap win.

**Requirements:** 1200×630 px, PNG, under 1 MB.

Easiest approach: take a clean screenshot of the recovery dashboard, paste it into a 1200×630 canvas over a dark indigo background, and add the app name plus one line of description. Figma, Canva, or Keynote all handle this in a few minutes.

Delete this README once you've added the image — anything in `public/` gets published.
